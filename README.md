# Pitchy

Pitchy 是一个完全在浏览器本地运行的实时练声 PWA。项目当前处于 `v0.1 / M4`：已接通自由/目标音练习、实时音高与稳定度反馈、Canvas 轨迹，以及会话统计和页面内结果预览；支持暗色 / 亮色主题和中英切换。

## 本地开发

要求 Node.js `>=24` 与 `pnpm 11.9.0`。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

完整验收：

```bash
pnpm check
pnpm typecheck
pnpm test
pnpm test:browser
pnpm build
pnpm test:e2e
pnpm check:size
```

首次运行浏览器测试前，可能需要执行：

```bash
pnpm exec playwright install chromium
```

## 当前边界

- 生产运行时无后端、无机器学习、无第三方分析或字体 CDN。
- 原始 PCM 和录音默认不保存、不上传。
- 主题、语言和 A4 基准通过 Dexie / IndexedDB 设置仓库保存，不发送到网络。首次使用数据库时事务性迁移旧 `pitchy.ui.theme` / `pitchy.ui.locale`；已有数据库设置优先。旧键保留为兼容缓存。
- 当前页面只会在用户明确点击后请求麦克风权限并创建或恢复 AudioContext；支持暂停、恢复和停止，停止或卸载时会断开输入节点、关闭上下文并停止全部轨道。
- 暂停期间本次练习仍持有麦克风轨道；停止后才会完全释放。页面隐藏时会暂停已运行的会话或取消尚未完成的启动，恢复可见后不会自行恢复音频。
- AudioWorklet 会将输入声道下混为单声道，并按 4096 samples / 2048 samples hop 生成可转移的 `Float32Array` 帧；音频图以零增益连接到输出，麦克风声音不会回放。
- Dedicated Worker 负责去直流 AC RMS / 近似 dBFS、自适应噪声门、YIN、voiced 判定、倍频跳变保护、时间中值滤波和约一秒的稳健稳定度统计，只把不含 PCM 的小型结果返回主线程。
- 每个有效 Worker 结果直接进入固定容量 Canvas 缓冲区；React 仅订阅约 25 Hz 的节流主读数。主题或语言切换不会重建 AudioContext、Worker 或当前练习会话。
- 自由练声已支持自动音名与「音中心偏差」：偏差相对最近十二平均律半音中心，正值偏高、负值偏低，不代表唱准率。开始前可设置 A4 基准 415–466 Hz（支持小数，默认 440）；练习与暂停期间锁定，停止后可修改，刷新后恢复本机保存的基准。
- 目标音模式可选择 D2–C6（此范围在所有支持的 A4 基准下均处于检测范围内）。「目标音偏差」保留完整半音/八度距离，主读数始终显示实际检测音；指针超过 ±50 音分时停在边缘并显示提示，数值不截断。
- 目标命中时长采用 ±20 音分（含边界）；稳定命中还要求稳定状态。仅累计前后均命中的相邻音频帧间隔，第一帧、缺帧、静音或暂停边界不补算；这是实时检测时间估计，不是唱功评分。自由模式不生成目标统计。模式、目标和 A4 均在开始后锁定，停止后可切换且新练习清零统计。
- 停止或异常中断后会保留本次结果：总时长（从音频运行至结束，含暂停）、有效发声与稳定时长、最长稳定长音、稳定音域、近似稳定度中位数，以及目标模式的 ±10/20/30 音分时间占比。占比分母是相邻有效音高帧覆盖的发声时间；没有有效区间时为「数据不足」，自由模式目标比例为 null。
- 会话聚合使用固定 1001 格直方图计算按时长加权的稳定度中位数（0.1 分精度），轨迹概览最多 300 点，通过逐对压缩保留断点，不能用作精细逐帧分析。数据不包含 PCM；设备名称当前未暴露，摘要保留 null。
- 结果可显式「保存本次摘要」到本机，支持删除本次已保存摘要，以及二次确认后清空全部练习数据（保留界面设置）。重复保存同一会话按 ID 更新。刷新后可查看已保存数量；完整历史浏览属于 VT-022。未保存预览会在刷新或开始下一次练习后丢失。
- IndexedDB 数据库 `pitchy-local` 初始版本为 1，设置及摘要带 `schemaVersion: 1`。Zod 严格校验字段、有限数值、指标一致性和轨迹长度；未知版本/异常会话跳过并提示可清空，损坏设置回退到可用默认值且允许重新选择修复。存储失败不阻止练习，设置读取超过 3 秒会降级并提示。浏览器清理站点数据也会删除本机记录，无云端备份。
- 当前尚未实现完整总结/历史页；稳定度阈值只有确定性合成信号依据，尚未完成真实麦克风标定、移动 Safari 或真实 20 分钟运行检查。
- 本产品不用于医疗诊断，也不能替代声乐老师或专业检查。
